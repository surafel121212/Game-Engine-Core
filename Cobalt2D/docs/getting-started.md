# Getting started

1. Install Android Studio with SDK 35, NDK 27, and CMake 3.22.
2. Open the `android/` folder.
3. Select the `app` run configuration.
4. Launch on an Android 7.0+ device or emulator.
5. Keep engine code under `engine/`, project content under `Examples/` or
   `Assets/`, and platform entry points under `android/`.

For desktop module checks, use the CMake commands in the root README. The
tests do not require an Android device.
