# Cobalt2D Platformer Example

This small example is intentionally plain-text so it can be opened on Android,
desktop tooling, or a CI runner without binary assets.

- `Scenes/Level1.scene` demonstrates a human-readable scene hierarchy.
- `Scenes/Level1.tilemap` demonstrates grid/layer data.
- `Scripts/Player.lua` demonstrates movement, jumping, and collision callbacks.

A production game can replace the scene data with imported sprites, animation
clips, audio assets, and a custom native component without changing engine code.
