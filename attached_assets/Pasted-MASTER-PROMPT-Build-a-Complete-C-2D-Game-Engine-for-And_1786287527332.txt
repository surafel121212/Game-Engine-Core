MASTER PROMPT — Build a Complete C++ 2D Game Engine for Android

You are an expert C++ game-engine architect, Android NDK developer, graphics programmer, tools programmer, UI/UX engineer, build-system engineer, and GitHub Actions engineer.

Build a complete, production-oriented 2D game engine and editor from scratch.

The engine should be inspired by the workflow and usability of engines such as Godot and Unity, but it must be an original implementation. Do NOT copy proprietary code, assets, branding, UI, or source code from any existing engine.

The primary target platform is Android.

The engine itself must be written primarily in modern C++ (C++17 or newer).

The final repository must be a complete Android-ready project that can be pushed to GitHub and built into an APK using GitHub Actions.

IMPORTANT:

- Do NOT focus on building the APK inside Replit.
- The goal is to generate the COMPLETE SOURCE PROJECT.
- The project must contain everything required for a later Android build.
- GitHub Actions must be configured to build the Android application.
- The engine must be usable as a real 2D game-development framework, not merely a demo.
- Do not create fake placeholder systems that pretend to work.
- Implement working systems wherever reasonably possible.
- Keep the architecture modular and extensible.
